# 📱 Parental Screen Tracker - React Native Mobile App

একটি সম্পূর্ণ ক্রস-প্ল্যাটফর্ম (Android / iOS / Web) মোবাইল অ্যাপ্লিকেশন যা একই PostgreSQL 16 ডাটাবেস ও FastAPI ব্যাকএন্ডের সাথে যুক্ত থাকে।

---

## ✨ প্রধান ফিচারসমূহ:
1. **লাইভ মনিটরিং (Home Screen):**
   - ডিভাইস অনলাইন/অফলাইন পালস।
   - বর্তমানে কোন অ্যাপ ও উইন্ডো টাইটেল চলছে তা প্রতি ৫ সেকেন্ডে অটো-রিফ্রেশ।
   - **ইমার্জেন্সি স্ক্রিন লক (Emergency Lock):** মোবাইল থেকে এক ট্যাপে যেকোনো সময় ল্যাপটপের স্ক্রিন লক করা।
   - **স্টাডি মোড (Study Mode):** পড়ার সময় গেম ও চ্যাট অ্যাপ ব্লকিং টগল।
   - মোট স্ক্রিন টাইম, গেমিং, স্টাডি ও ব্রাউজিং টাইমের রঙিন কার্ড।
2. **রুলস ও লিমিট নিয়ন্ত্রণ (Rules Screen):**
   - প্রতিটি অ্যাপের দৈনিক সময়সীমা দেখা ও পরিবর্তন।
   - অ্যাপ ব্লক বা আনব্লক সুইচ।
   - মোবাইল থেকেই নতুন কোনো অ্যাপ বা গেমের রুল যোগ করার মডাল।
3. **লাইভ টাইমলাইন (Timeline Screen):**
   - উইন্ডোজ পিসির প্রতিটি অ্যাক্টিভিটি লগ (অ্যাপ নাম, উইন্ডো টাইটেল, ক্যাটাগরি ও সেকেন্ড)।
4. **অ্যালার্ট হিস্ট্রি (Alerts Screen):**
   - বাচ্চার স্ক্রিনে প্রদর্শিত ৫ মিনিট বাকি ওয়ার্নিং, লিমিট এক্সিডেড নোটিফিকেশন ইত্যাদির হিস্ট্রি।
5. **সার্ভার কানেকশন (Settings Screen):**
   - ল্যাপটপের লোকাল আইপি (যেমন: `http://192.168.1.100:8000`) বা ক্লাউড/টানেল ইউআরএল সেট ও টেস্ট করার অপশন।

---

## 🚀 কীভাবে মোবাইল অ্যাপ চালাবেন (How to Run):

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
cd mobile_app
npm install
```

### ২. অ্যাপটি চালু করুন (Expo / React Native):
```bash
npx expo start
```
- **Android ফোনে চালাতে:** মোবাইলে `Expo Go` অ্যাপ ডাউনলোড করে টার্মিনালের QR কোড স্ক্যান করুন।
- **Web ব্রাউজারে চালাতে:** টার্মিনালে `w` প্রেস করুন।
- **Android Emulator-এ চালাতে:** টার্মিনালে `a` প্রেস করুন।

### ৩. একই ডাটাবেসে কানেক্ট করার নিয়ম:
মোবাইল অ্যাপের **সেটিংস (🛠️)** ট্যাবে গিয়ে আপনার পিসির লোকাল আইপি অ্যাড্রেসটি লিখুন:
```text
http://[আপনার-পিসির-IP-ঠিকানা]:8000
```
উদাহরণ: `http://192.168.0.105:8000`
(ল্যাপটপ ও মোবাইল একই ওয়াইফাই রাউটারে যুক্ত থাকলে স্বয়ংক্রিয়ভাবে ডাটা সিঙ্ক হবে। এছাড়া ngrok বা Cloudflare Tunnel দিয়ে বিশ্বের যেকোনো প্রান্ত থেকে ইন্টারনেট দিয়েও কানেক্ট করা যাবে।)
